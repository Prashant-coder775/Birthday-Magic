BIRTHDAY MAGIC — QUICK START

Files:
- index.html
- style.css
- script.js

Run locally:
1. Extract the ZIP.
2. Open the birthday_magic folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Enter a name and press Celebrate.

Personalized sharing:
- The Copy link and WhatsApp buttons create a URL with ?name=PersonName.
- To share it with other people over the internet, first publish the folder using GitHub Pages, Netlify, or another static hosting service.
- A local file URL only works on your own computer; it is not a public shareable link.

Notes:
- The celebration tune is generated in the browser after the visitor presses Play.
- The page uses Google Fonts when internet access is available; fallback fonts are included.
